项目概览

当前库里的材料与编码进度

三步开始

  1. 导入材料 — 在「材料」页拖入 Word / PDF / txt 逐字稿，或整文件夹批量导入。系统按文件名推断编号、日期、轮次，并切成带编号的段落。
  2. 区分与脱敏 — 在「受访者」页确认归属与阶段，维护真实姓名→化名映射，一键应用到全部原文。
  3. 编码与导出 — 在「编码」页建码本、给段落打码；用「检索与矩阵」看分布；在「导出」页拿清单、交叉表、引语汇编。

关于「可核查」

每个段落都有唯一编号（如 P01-003）。检索结果、交叉矩阵、引语汇编都带受访者编号、材料标题、访谈日期与阶段，写论文时可直接回溯核对。系统不对原文做润色、缩写或自动摘要。

写作提示

引语汇编里的每条原话都带「受访者编号 / 材料 / 段落号 / 访谈日期 / 阶段」。正式引用前请对照原始录音或转录稿再核一次；本工具不替你判定引语的代表性，也不生成分析结论。

设置与运行信息

时间阶段（纵向研究分组）

每行一个阶段名。导入材料时可选，用于按阶段比较码号分布。

录音转写（可选模块）

首次使用需联网下载一次模型；转写结果不自动区分说话人，请在「材料」页批量标注并人工核对错字。

更省事的路径：用支持说话人分离的外部转写工具导出 .srt / .vtt / .json，再在「材料」页导入，说话人标签会保留。

路径与版本

研究伦理与部署边界

服务只监听 127.0.0.1，不要改成 0.0.0.0 或部署到公网服务器。访谈原文含个人信息和机构细节，data/ 与 export/ 已写入 .gitignore，推送到 GitHub 前请再确认一次没有把原始材料提交进仓库。
